This face-recognition project explores how Python and OpenCV can be used to detect and recognise faces through a webcam. It is designed to locate faces in video frames, collect facial samples, train a recognition model, and compare new faces against enrolled users.

The project also explores facial-feature analysis to develop a deeper understanding of how computer vision represents and distinguishes faces. It brings together camera input, image preprocessing, face detection, model training, and recognition within an interactive application.

Developed as a hands-on learning project, it provides practical experience in computer vision, machine learning, and Python programming. It also creates opportunities to investigate how lighting, camera angles, facial expressions, and image quality influence recognition performance, with room for future improvements in accuracy, reliability, and usability.
